# Mini-Project-Data-Analysis-using-Excel-PowerBI


# 🎬 Netflix Data Analytics & Dashboard

## 📌 Project Overview

This project focuses on analyzing the Netflix Movies and TV Shows dataset to uncover meaningful insights about Netflix's content library.

The project involved **data cleaning, transformation, exploration, analysis, and visualization** using **Microsoft Excel and Power BI**. An interactive dashboard was created to present key findings in a simple and visually appealing way.

## 🎯 Project Objective

The main objective of this project is to analyze Netflix's content and identify trends based on:

* Movies vs. TV Shows
* Release years
* Genres
* Countries
* Ratings
* Duration
* IMDb ratings
* Content distribution and popularity

The dashboard helps users understand Netflix's content catalog and discover important patterns and insights.

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning, transformation, filtering, sorting, and preliminary analysis
* **Power BI** – Data modeling, DAX calculations, and interactive dashboard creation
* **Power Query** – Data transformation and preparation
* **DAX** – Calculated measures and analytical calculations

## 📂 Dataset

The project uses a Netflix Movies and TV Shows dataset containing information such as:

* Show ID
* Title
* Type
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Listed In / Genre
* Description
* IMDb Rating

The dataset was cleaned and prepared before being used for analysis and visualization.

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

* Removed duplicate records
* Identified and handled missing values
* Standardized column formats
* Converted columns to appropriate data types
* Handled missing duration values
* Standardized date and numerical fields
* Checked data consistency
* Filtered and sorted data for analysis

## 📊 Power BI Dashboard

The interactive dashboard provides insights through different visualizations, including:

* **Total Titles**
* **Movies vs. TV Shows**
* **Content by Genre**
* **Top Countries by Number of Titles**
* **Content Distribution by Release Year**
* **Netflix Titles by Country**
* **Top IMDb-Rated Titles**
* **Ratings and Duration Analysis**

The dashboard is designed to make the analysis easy to understand and visually engaging.

## 🔍 Key Insights

Some of the insights explored through the project include:

* Netflix has a larger number of **Movies than TV Shows** in the analyzed dataset.
* The Netflix content library expanded significantly over the years.
* Certain countries contribute a much larger share of Netflix's content than others.
* Drama, comedy, and other popular genres form a significant portion of the catalog.
* IMDb ratings can be used to identify highly rated titles within the dataset.

## 💡 Recommendations

Based on the analysis, Netflix could:

* Continue investing in high-performing and popular genres.
* Explore opportunities in countries with lower content representation.
* Use viewer and rating trends to support content acquisition decisions.
* Analyze highly rated content to identify patterns that could guide future content strategies.
