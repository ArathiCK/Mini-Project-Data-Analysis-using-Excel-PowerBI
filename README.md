# 🎬 Netflix Data Analytics & Dashboard

## 📌 Project Overview

This project analyzes the **Netflix Movies and TV Shows dataset** to uncover meaningful insights and trends in Netflix's content library. The project includes data cleaning and preparation in **Excel**, followed by data analysis and interactive visualization using **Power BI**.

Live Dashboard & PowerBI Presentation Included

## 🎯 Project Objective

The main objective of this project is to explore Netflix's content and understand patterns based on **content type, genres, countries, release years, ratings, duration, and IMDb ratings**. The project aims to transform raw data into meaningful insights through effective data analysis and visualization.

## 📊 Key Analysis Conducted

* Analyzed the distribution of **Movies vs. TV Shows**
* Examined Netflix content across different **genres**
* Identified the **top countries** contributing to Netflix's content
* Analyzed the growth and distribution of content across **release years**
* Studied the distribution of **ratings**
* Analyzed **movie and TV show duration**
* Identified **top IMDb-rated titles**
* Explored the geographical distribution of Netflix titles using a **map visualization**
* Created an interactive **Power BI dashboard** to present key findings and insights

## 👩‍💻 About the Project

This project is part of my **Data Analytics learning journey** and was created to gain practical experience in working with real-world datasets.

Through this project, I practiced **data cleaning, data transformation, data analysis, data modeling, DAX, and data visualization** using Excel and Power BI. The final dashboard presents the analysis in an interactive and easy-to-understand format.
